# Wasteland Story item catalog

Offline, searchable catalog for game build 26.12.23 (1290).

- All 1,139 extracted item IDs and 1,145 definitions.
- Compact grid, game category filters, sprites, and detailed item dialogs.
- Built-in effect descriptions and recovered base definition stats.
- TB/XTB field reference; actual saved-item values require a save file.

Open `index.html` locally, or visit the GitHub Pages site. Everything is embedded; no backend, account login, analytics, or external dependencies are required.

## Update

Replace `index.html` with the latest exported catalog and push to `main`. GitHub Pages publishes the repository root.

## Data scope

This unofficial catalog contains extracted game descriptions and images. Game names and assets belong to their respective owners. Data describes the supplied client build and does not establish current item availability or server acceptance. No account data or save files are included.
